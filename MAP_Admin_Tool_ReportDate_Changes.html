MAP Admin Tool — Report Date now works with one day

Every change, side by side. Left is the code before, right is the code after. In total there are 19 changes: 4 in 2 files of the app and 15 in 5 database functions (the same 3 small changes in each function). In the new code every old line is kept as a comment, and the new line is placed right under it.

The change in short

  • Before: the Report Date field opened on the Sunday of the current week. When the user picked a date, the page moved it back to the Sunday of that week, and the database returned the notifications of the week.
  • Now: the Report Date field opens on today's date. When the user picks a date, the page keeps that date, and the database returns only the notifications with a GenerationDate on that day.
  • The same rule is used by the notifications table, the Seller Name filter, the Contacts page and the two export functions.
  • All new comments start with the text Report Date single day - 11/16/26, so you can find every change with a simple search.

Change 2

MAP_Admin_Tool/MAP_WebApp/MAP_WebApp/Pages/Index.cshtml.csline 80

What changed and why
